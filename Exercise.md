# Assessment with Product Framing

## Expectations

This exercise is intentionally designed to assess how you think, design, and build software in an AI-driven environment.

You are required to use AI tools to accelerate your work. We care about how you use them, the clarity of your thinking, and the quality of your engineering decisions.

We expect you to:

- Demonstrate clarity in thought and structured problem solving
- Show strong engineering fundamentals and product thinking
- Make thoughtful architectural and design decisions
- Write production-quality code and tests
- Use AI intentionally while maintaining correctness and quality
- Make incremental commits so we can understand how your solution evolved

---

# Goal

Build **employee salary management software** for an organization with **10,000 employees**.

## User Persona

**HR Manager** of the organization.

---

# Problem Statement

Currently, ACME organization's HR team manages salary data for **10,000 employees across multiple countries** using Excel spreadsheets.

This process is tedious and difficult to manage.

We want the HR Manager to manage salary data through a **web-based application** and be able to answer questions about **how the organization pays its employees**.

---

# Requirements

Before building the software, write a **one-page requirements document** outlining:

- Goal
- Scope
- Features
- What you are deliberately leaving out
- Reasoning behind the decisions

---

# Technical Constraints

You should build an **end-to-end, fully functional software application**, including both:

- Backend
- UI

## Backend

- Language and framework as per the JD (preferred), or any other framework of your choice
- Relational database of your choice, such as SQLite

## UI

Choose one of:

- ReactJS
- NextJS
- AngularJS with Java

Use a component library of your choice.

---

# Seeding

Provide a seed script that creates data for:

- **10,000 employees**

The seeded data should be realistic enough to demonstrate the application's functionality.

---

# Readiness

The final solution should include:

- Fully functional deployed software
- Video demo of the software

---

# Development Approach

Using **agentic AI tools** of your choice, build the solution while maintaining high standards of code quality and test coverage.

Your solution should include:

## Tests

- A meaningful set of unit tests covering core functionality
- Tests that are:
  - Fast
  - Deterministic
  - Easy to understand

## Code Quality

The code should demonstrate:

- Good structure
- Readability
- Maintainability
- Production-quality implementation

## Commit History

Your Git commit history should show the **evolution of your solution through incremental commits**.

This helps us understand:

- How you approached the problem
- How you broke down the work
- How your implementation developed over time

---

# Artifacts

Along with your solution, commit any artifacts that help us understand your thinking and approach.

Examples include:

- Requirements document
- Planning or design notes
- Architecture diagrams
- Prompts or instructions used with AI tools
- Trade-off explanations
- Performance considerations

There is no required format.

Use whatever format best explains your approach.

---

# How to Succeed in This Assessment

The strongest submissions typically demonstrate:

- Clear thinking and structured problem solving
- Thoughtful architecture and design decisions
- Clean, maintainable code
- Meaningful tests
- Intentional use of AI tools
- Evidence of product thinking

> We are not looking for the most complex system, but for good engineering judgment.
